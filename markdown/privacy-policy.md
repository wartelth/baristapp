# SwissKnife Privacy Policy (Draft)

Last updated: 2026-02-16

## What we collect

- Prompts you submit to generate or modify mini-apps.
- Generated mini-app specifications (JSON).
- Mini-app runtime state (JSON).
- Device identifier when you are not signed in.
- Account identifier token when you are signed in.

## How we use data

- To generate and modify mini-apps.
- To save your mini-apps and sync state across sessions.
- To maintain reliability and abuse reporting workflows.

## Third-party processors

- Anthropic (Claude): prompt processing for generation/modification.
- Supabase: cloud data storage.

## Data controls

- You can withdraw processing consent in the Profile screen.
- You can request deletion of all cloud and local mini-app data from the Profile screen.
